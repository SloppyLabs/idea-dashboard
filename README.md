# 💡 Idea Lab — Autonomous Research Archive

A warm-toned, easy-on-the-eyes dashboard for browsing **95 autonomously researched startup/project ideas**, each scored on Uniqueness × Demand with full landscape analysis, competitor research, and refinement notes.

![Idea Lab Dashboard](https://img.shields.io/badge/ideas-95-orange) ![Hits](https://img.shields.io/badge/hits-33-orange) ![Hit Rate](https://img.shields.io/badge/hit%20rate-35%25-amber)

## Features

- **Card Grid** — Browse all ideas at a glance with score bars, decision badges, and domain tags
- **Detail Overlay** — Click any card for a full-screen modal with problem, solution, audience, landscape research, competitors, demand signals, and refinement notes
- **Filter & Search** — Filter by decision (Hit / Refined / Killed) and full-text search across titles, domains, problems, and solutions
- **Live Stats** — Total ideas, hit rate, average uniqueness/demand scores
- **Warm Palette** — Designed for extended reading sessions; dark warm-brown background with orange/amber accents
- **Zero Dependencies** — Self-contained single HTML file. No npm, no build step needed to deploy.

## Quick Start

```bash
# Just open it
open index.html

# Or serve locally
python3 -m http.server 8000
# → http://localhost:8000
```

## Rebuild from Source

If you want to regenerate from the idea log (e.g. after new ideas are added):

```bash
python3 build.py
```

This parses `idea-research-log.md`, updates `data/ideas.json`, and rebuilds `index.html` with the latest data inlined.

## Deploy

The `index.html` is fully self-contained (CSS, JS, and data all inlined). Deploy anywhere:

- **Vercel/Netlify**: Drag-and-drop the folder or connect the repo
- **GitHub Pages**: Push to `gh-pages` branch or enable Pages on `main`
- **Any static host**: Upload `index.html`

No server, no database, no runtime dependencies.

## Data Source

Ideas are generated by an autonomous research agent that runs on a 3-hour loop, discovering, validating, and scoring startup ideas on two axes:
- **Uniqueness (1–5)**: Is the concept genuinely novel and unowned?
- **Demand (1–5)**: Is there active, recurring community demand?

Ideas scoring ≥4 on both axes are marked as **Hits** (★).
